Настрой свой адрес

Каждый адрес проверяем сразу по всем шаблонам. Совпадение сохраняем и продолжаем по оставшимся.

MAX: все потоки CPU и 100% активности GPU. Автоснижение отключено; компьютер может тормозить.

Максимум скорости по свободным ресурсам. При нагрузке других программ поиск замедляется, в игре — пауза. Ползунки задают пределы.
