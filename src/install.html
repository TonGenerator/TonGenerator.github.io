СОХРАНИ РЕЗУЛЬТАТ

Два важных файла

Результаты появятся в папке:

~/.generator-ton-username/wallets/
  • wallet-….encrypted.json — зашифрованный кошелёк;
  • recovery.key — ключ для его открытия.

Сделай копию обоих файлов. Не загружай ключ и секретные копии в GitHub.

Как получить слова для импорта

Вставь имя найденного файла вместо ИМЯ. JSON с открытыми словами сохранится в текущей папке.

./generator-ton export \
  --file ~/.generator-ton-username/wallets/wallet-ИМЯ.encrypted.json \
  --output SECRET-TON-backup.json

Слова в терминал не выводятся. Для импорта выбери ту же версию кошелька.

GOOGLE COLAB

Генератор с кнопками. В облаке.

Выбор кошелька и устройства, тест скорости, запуск, пауза и остановка. Живая скорость, ожидаемая дата нахождения и даты для шансов 50% / 95%. Результат скачивается отдельной кнопкой.

↓ Скачать блокнот Colab↓ Скачать исходникиОткрыть Google Colab ↗
  1. Скачай блокнот и исходники. В Colab: Файл → Загрузить блокнот, выбери .ipynb.
  2. Для GPU: Среда выполнения → Сменить среду выполнения → GPU. Затем запусти ячейку ▶ и выбери ZIP исходников.
  3. В появившейся панели нажми Подготовить среду, затем Тест скорости или Начать поиск.

GPU требует WebGPU/Vulkan: доступ проверяется при подготовке. Если драйвер Colab несовместим, выбери CPU. Ожидаемая дата — оценка без гарантии; короткий тест остановится по таймеру.

Секретные слова создаются в облаке Google. Старые сид-фразы не нужны. Скачай результат до отключения среды. Архив с ключом даёт доступ к кошельку — храни его у себя.

Не хватает утилит или команда не найдена

На Ubuntu / Debian установи необходимые утилиты и повтори команды выше.

UBUNTU / DEBIAN
sudo apt-get update
sudo apt-get install git curl ca-certificates xz-utils unzip

CPU проверен на Debian и Windows. GPU дополнительно проверен на Windows; на Linux нужен рабочий драйвер с Vulkan. Linux-версия не определяет игры автоматически — нагрузку GPU можно уменьшить через --gpu-load.
