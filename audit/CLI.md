# Консольная версия

CLI работает на Node.js 22+ без браузера и локального сервера. Команды и установка описаны в README. Linux-установщик поддерживает x64/arm64, использует установленный Node либо проверенный по SHA256 архив Node.js 24 с nodejs.org. Он не меняет системный Node. CPU не требует сборки browser bundle или GPU-пакета. Генерация BIP39 использует системный PBKDF2-HMAC-SHA512 внутри каждого worker, затем общий проверенный SLIP-0010/Ed25519 и стандартные TON-контракты. Победитель повторно проверяется независимым каноническим путём. 24 слова TON поддерживаются для V4/V5.

GPU — необязательный Node-модуль webgpu 0.6.2 (Dawn). Используются те же ограниченные WGSL-команды, контрольные векторы, проверки порций и проверка результата, что в браузере. Небезопасные опции Dawn и отключение проверок не включаются. Нативный GPU и его проверяющие потоки живут в отдельном дочернем процессе: проверка выявила N-API abort при остановке обычного worker во время инициализации драйвера, поэтому принудительное завершение такого worker в основном процессе исключено. Дочерний GPU-процесс завершается целиком, его native crash не прерывает основной процесс или запись кошелька. Слова победителя идут по приватному IPC только после нахождения; прогресс не содержит слов. При отказе GPU hybrid продолжает CPU. Обнаружение игр и внешней нагрузки GPU из Windows helper в Linux CLI не переносится; CPU регулируется по внешней системной нагрузке и задержкам управляющего цикла с учётом CPU GPU-процесса, GPU — программным лимитом. Программный duty не равен показаниям диспетчера нагрузки.

Новые секреты создаются из Web Crypto entropy внутри worker. Прогресс и JSON stdout содержат только открытые сведения. Фраза передаётся в main только после нахождения, шифруется AES-256-GCM со случайными 12-байтными IV и 256-битным локальным ключом; метаданные привязаны через AAD. На POSIX новые файлы — 600, папки — 700. Ключ и зашифрованный файл лежат в одной пользовательской папке; это не защита от кражи всей папки, злоумышленника текущего пользователя или скомпрометированной ОС. На Windows mode не заменяет NTFS ACL. DPAPI Windows-приложения здесь не используется. Нужна резервная копия обоих файлов.

Открытый экспорт требует отдельной команды и нового выходного файла, слова не печатаются. При ошибке сохранения найденного результата worker/фраза удерживаются, запись повторяется. Доступные буферы очищаются, но JS-строки и физическое стирание всех копий памяти не гарантированы. Поиск не отправляет сетевых запросов, не выполняет транзакции. Установка npm/runtime требует сети. Результаты, ключи, пользовательские логи, зависимости и runtime исключены из Git и исходного архива. Архив собирается по списку разрешённых исходных каталогов.

Локально проверены CLI для Telegram, V4R2/V5R1, BIP39 и 24 слова TON, каноническое восстановление по словам, отсутствие слов в выводе, шифрование/аутентификация, права файлов POSIX, запрет перезаписи экспорта и завершение по таймеру. Семь CLI-тестов прошли на Windows и Debian/WSL с Node.js 22.22.3; полный набор — 59/59. На настоящем GPU Windows нативный модуль нашёл тестовый WalletTg, копия расшифрована и канонический адрес подтверждён; слова не выведены. Из-за сбоя npm-клиента тестовый webgpu получен напрямую из официального registry и проверен по опубликованному SHA512. GitHub Actions подготовлен для Ubuntu 24.04/Windows на Node 22/24; до публикации workflow на GitHub ещё не запускался. GPU на Linux требует подходящего драйвера и отдельной проверки на целевой машине.

Источники: [Node.js crypto](https://nodejs.org/docs/latest-v24.x/api/crypto.html), [webgpu / Dawn](https://github.com/dawn-gpu/node-webgpu), [официальные сборки Node.js 24](https://nodejs.org/dist/latest-v24.x/).
